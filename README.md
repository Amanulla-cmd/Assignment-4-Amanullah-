Assignment Tasks

Task 1 – Data Design Review

Analyse the problems in a patient register using parallel arrays and redesign it using structures and nested structures.

Task 2 – Courier Parcel Tracking

Design nested structures to store parcel details, sender and receiver information, booking dates and parcel weights. Implement sorting and searching operations.

Task 3 – Structures and Unions

Study and implement structures and unions, including memory allocation, storage and accessing members.

Task 4 – Structure Handling and Debugging

Identify and correct errors in structure handling using appropriate C programming techniques.

Task 5 – Storage Classes

Implement and compare automatic, static, extern and register storage classes.

Task 6 – College Canteen Inventory and Billing

Develop a structure-based application to manage canteen items, stock, sales, expiry dates and daily bill summaries.
